# dym_ui

Design system DYM « Le marché de Lomé, livré chez toi » (catégorie `ui`).

- Thème généré depuis [`docs/design/tokens/dym.tokens.json`](../../../docs/design/tokens/dym.tokens.json)
  par `tool/generate_tokens.dart` (`fvm dart run melos run tokens`). Ne jamais modifier
  `lib/src/tokens/dym_tokens.g.dart` à la main.
- Polices embarquées : Nunito et Nunito Sans (variables, licence OFL, dossier `fonts/`).
- Composants : voir le contrat [`specs/001-dym-ui-design-system/contracts/dym_ui-components.md`](../../../specs/001-dym-ui-design-system/contracts/dym_ui-components.md).
- Aucun texte en dur : les libellés sont passés par l'appelant.

Galerie de validation : `apps/dym_gallery`.
