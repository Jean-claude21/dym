# dym_core

Fondation DYM en Dart pur (catégorie `foundation`, aucune dépendance Flutter).

- `Money` : montant en unités mineures (entier) + `Currency` ISO 4217. Jamais de flottant.
- Formatage selon la devise et la locale du pays : « 4 100 F CFA », « GH₵88.15 ».

Tests : `fvm dart run melos run test:dart`.
