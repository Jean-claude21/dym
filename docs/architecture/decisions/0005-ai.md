# 0005 — IA via AI SDK et OpenAI, sans AI Gateway

**Statut :** Acceptée · 2026-10-01

## Contexte

AI Gateway de Neon est réservé au plan Pro. Une clé OpenAI est disponible. On veut pouvoir changer
de fournisseur ou de modèle sans redéployer les apps.

## Décision

- Bibliothèque : **AI SDK 7** (`ai` + `@ai-sdk/openai`), exécutée dans les Neon Functions (Node 24).
- Sorties structurées validées par `zod` (ex. fiche produit proposée depuis une photo).
- Le modèle utilisé pour chaque usage est lu dans la table `ai_models`, pas codé en dur.
- La clé est un secret de Function ; elle n'est jamais présente dans une app.
- Chaque appel est journalisé dans `ai_requests` (usage, modèle, latence, succès, coût estimé) et
  limité par utilisateur.

## Conséquences

- Phase 2 : photo → nom, catégorie et description (V-PROD-02).
- Phase 4 : transcription vocale, recherche par image (embeddings + pgvector), copilote d'intention.
- Toute fonction IA a un repli sans IA (saisie manuelle, recherche classique).

## Alternatives écartées

AI Gateway (plan Pro) ; SDK officiel `openai` seul (couplage au fournisseur) ; appel direct depuis
l'app (clé exposée).
